# Week 2 — Data Sourcing & Collection Strategy

## Project
**Customer Review Sentiment Analysis for Beauty Product Insights**

Week 2 focuses on identifying, evaluating, and planning the collection of public data relevant to the Beauty & Wellness customer-review sentiment analysis project.

## Contents
- `Week_2_Data_Sourcing_and_Collection_Strategy.docx` — complete Week 2 report
- `data_source_register.md` — public data sources, links, strengths, limitations and selection notes
- `data_quality_checklist.md` — initial data-quality and relevance checks
- `notebooks/02_week2_data_source_planning.ipynb` — planning notebook for source selection and initial audit
- `docs/week2_variables.md` — required and derived variables

## Important
This week is a planning and sourcing deliverable. No analytical results are fabricated. Actual statistics and visualizations will be generated after the selected dataset is collected and inspected.

## Primary candidate
Amazon All Beauty Reviews dataset:
https://huggingface.co/datasets/jhan21/amazon-beauty-reviews-dataset

## GitHub note
Large raw datasets should not be committed to the public repository unless their terms explicitly permit redistribution. Store source information and reproducibility notes instead.
